LearnNOW — Plateforme de gestion de formations
================================================
Projet TP6 — ISET'COM L2-GTIC — 2025

INSTALLATION
------------
1. Copier le dossier GestionFormations dans htdocs/ (XAMPP)
2. Importer database.sql dans phpMyAdmin
3. Ouvrir : http://localhost/GestionFormations/

IMAGES A REMPLACER
------------------
Les fichiers suivants sont des placeholders.
Remplacez-les par de vraies photos :

  assets/images/hero.jpg       → Photo principale de la page d'accueil
                                  Recommandé : 1600x900px minimum
                                  Thème : salle de cours, ordinateur, étude

  assets/images/web.jpg        → Photo pour la formation Développement Web
  assets/images/data.jpg       → Photo pour la formation Data Science
  assets/images/ia.jpg         → Photo pour la formation IA
  assets/images/cyber.jpg      → Photo pour la formation Cybersécurité
  assets/images/default.jpg    → Image par défaut si aucune image trouvée

  Recommandé : 800x450px, format JPG, poids < 200Ko

TUNNEL COMPLET
--------------
Accueil → Formations → Détail → Inscription → Paiement → Succès → Cours
                                                                 → Profil
